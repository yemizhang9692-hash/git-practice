# Git 练习仓库

这个文件夹是我练习 Git 用的，不是正式项目。

## 这个仓库用来干什么

1. 熟悉 `add → commit → log` 这套最基本的流程
2. 练习改文件之后看 diff、回退单个文件
3. 练熟了再绑 GitHub，把代码推上去

## 常用命令速查

| 命令 | 作用 |
| --- | --- |
| `git status` | 看当前有哪些改动 |
| `git add .` | 把改动标记为"准备提交" |
| `git commit -m "说明"` | 拍一个快照 |
| `git log --oneline` | 看历史快照列表 |
| `git diff` | 看具体改了哪几行 |
| `git checkout -- 文件名` | 丢弃某个文件的改动（慎用，不可恢复） |
